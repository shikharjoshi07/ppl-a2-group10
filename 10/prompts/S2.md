## Prompt 1 — understand the problem (no code)

```
S2, same restricted Racket (#lang racket/base, allowed built-ins in the project instructions, plus read for this one). Don't write code yet. Read the spec and tell me (1) how to decide whether an element is a sublist using only the allowed built-ins, given that () counts as a list, and (2) why the length has to be measured before inserting.

insert-if-short takes an atom x, a possibly nested list lst and an integer n, and inserts x at the front of every list whose length is less than n, at every level of nesting. Length = number of top-level elements of the original list, before insertion. The top-level list is treated like every other list. () has length 0, so it becomes (x) whenever 0 < n, also at the top level. Elements are atoms (digits or symbols) or lists, no dotted pairs. x is any atom, n >= 0.
S2.a (print-insert-result) takes no arguments, reads x, lst and n in that order with read, and displays the result followed by newline. No prompt, no other text.
S2.b Write my-length and my-map with the allowed built-ins only, and define (insert-if-short x lst n) using them.
S2.c Write a higher-order (make-inserter x len-ok?) that returns a one-argument function (a list) that inserts x at the front of every list, at every level, whose length satisfies len-ok? (a predicate on one number). Then redefine insert-if-short using make-inserter. The final file contains only that one definition of insert-if-short.
Examples (stdin -> output): 42 ((1 2) (3 4 5) (6) ()) 3 -> ((42 1 2) (3 4 5) (42 6) (42)). 0 (((1) 2) (3) ((4 5 6) ())) 3 -> ((0 (0 1) 2) (0 3) (0 (4 5 6) (0))). 7 () 3 -> (7). 7 () 0 -> ().
Hidden tests include nesting depth 100 and lists of 10,000 elements.
```
