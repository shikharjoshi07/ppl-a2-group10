## Prompt 1 — understand the problem (no code)

```
New problem, P2, SWI-Prolog 9. Don't write code yet. Read the spec and tell me (1) how you'd represent expression trees as Prolog terms, (2) how to make sure division is checked at every node, not just the top, (3) how to get no duplicates without ever parsing a string back into a term.

Given a list of non-negative integers, insert + - * / and exactly one = between the numbers (every number used once, in the given order, optional parentheses) so both sides have the same value. With the list n1..nk, an equation is L=R where L is an expression over n1..nj and R over n(j+1)..nk, for some 1 <= j < k. An expression is a single number, or two expressions joined by + - * /, optionally parenthesised. No unary minus, digits are never joined into bigger numbers, and sub-expression values may be negative. Division is allowed only when it's exact (integer, no remainder) and the divisor isn't 0, at every division in the expression. Both sides must have the same integer value.
Output: an SWI-Prolog string with no spaces, like "4*2=5+3". Parentheses rule: * and / bind tighter than + and -; operators are left-associative; a left operand is parenthesised only if its top operator has lower precedence than its parent's; a right operand is parenthesised if its top operator has the same or lower precedence than its parent's; a single number is never parenthesised. Examples: (4+2)*3, 4+2*3, 8/4*2, 8/(4*2), 1-2-3, 1-(2-3), 1+(2+3), 1+2+3 (different trees give different strings).
Tasks: generate_equation(List, Equation) gives one valid equation and fails (no loop, no error) when there is none, including for lists of length 0 or 1. all_equations(List, Equations) gives all of them, no duplicates, sorted by sort/2, [] if none. count_equations(List, N) gives the length.
Examples: all_equations([4,2,5,3], Es) gives ["4*2-5=3","4*2=5+3","4-2=5-3","4/2=5-3","4=2*(5-3)","4=2+(5-3)","4=2+5-3"]. [2,3,4] has none. all_equations([2,4,8], Es) gives ["2*4=8"].
No assert/retract/globals. Allowed libraries: lists, apply, yall, aggregate. No printing.
```

## Prompt 3 — expression trees with values

```
Write only expr(Nums, Tree, Value). Nums is a non-empty list of integers. It generates every expression tree that uses all of Nums in order, together with its integer value. A one-element list [N] gives Tree = N and Value = N. Otherwise split Nums with split/3 into Left and Right, recurse on both, and combine with one of +, -, *, / into a tree term like +(A,B) or '/'(A,B). For / only succeed when the right value is not 0 and LeftValue mod RightValue =:= 0, with Value is LeftValue // RightValue. Every recursive call must be on a strictly shorter list, so it terminates.
```

Build the string with format(string(S), ...) or string_concat/3. These must come out right: (4+2)*3, 4+2*3, 8/4*2, 8/(4*2), 1-2-3, 1-(2-3), 1+(2+3), 1+2+3. Show me the tree terms you'd use to check each one.
