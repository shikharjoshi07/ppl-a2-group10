# P1 prompts (ChatGPT), word for word, in the order they were sent

## Prompt 1 — understand the problem (no code)

```
I'm doing P1 of my PPL assignment in SWI-Prolog 9. Problem statement is below. Don't write any code yet. Just (1) restate each of the 8 clues as a constraint on the list [p('Alex',D1,L1,P1), p('Ben',D2,L2,P2), p('Carla',D3,L3,P3), p('Dana',D4,L4,P4)], and (2) tell me how many candidates a plain generate-and-test over permutations would have to check.

Four friends (Alex, Ben, Carla, Dana) each have a department, a favorite language and a project preference. Department: research, development, design, testing. Favorite language: python, java, c++, javascript. Project: AI, web, embedded, data. Every friend has a different value for each attribute, so each value is used exactly once.
Clues:
1. The friend who prefers the AI project does not work in research and is not Dana.
2. Alex does not work in development and does not prefer C++.
3. The friend working in the testing department likes Python.
4. Ben prefers web projects and does not work in testing.
5. The friend whose favorite language is Java works in the design department.
6. Carla's project preference is not embedded, and her department is not development.
7. Dana's favorite language is not Java, and she works in research or testing.
8. The friend who prefers data projects works in research and does not use JavaScript.
A solution is a list of four terms p(Name, Dept, Lang, Project) in the order Alex, Ben, Carla, Dana. Names are 'Alex','Ben','Carla','Dana'. Values are exactly: research, development, design, testing; python, java, 'c++', javascript; 'AI', web, embedded, data.
Each clue must be its own clause clue(N, Solution) that succeeds exactly when clue N holds in a fully filled-in Solution. No assert/retract/global variables. Allowed libraries: lists, apply, yall, aggregate.
```

## Prompt 2 — generator

```
Write only the generator, nothing else: candidate(S), which binds S to [p('Alex',D1,L1,P1), p('Ben',D2,L2,P2), p('Carla',D3,L3,P3), p('Dana',D4,L4,P4)] where the four departments, four languages and four projects are each a permutation of their values. Use permutation/2 from library(lists). Include the mode line and declarative reading comment.
```

## Prompt 3 — clues 1 to 4

```
Now write clue(1,S) to clue(4,S), one clause per clue. Each must succeed exactly when that clue holds in a fully ground S (the generator has already run). Use member/2 on S to find the friend with a given attribute. Put the English clue as a comment above each clause. "Does not prefer C++" in clue 2 means Alex's language is not 'c++'.
1. The friend who prefers the AI project does not work in research and is not Dana.
2. Alex does not work in development and does not prefer C++.
3. The friend working in the testing department likes Python.
4. Ben prefers web projects and does not work in testing.
```
