## Prompt 1 — understand the problem (no code)

```
S1 of my PPL assignment, Racket 8 with #lang racket/base and a restricted set of built-ins (it's in the project instructions). Don't write code yet. Read the spec and tell me (1) which built-ins I'd normally reach for here that are banned and what I'll use instead, and (2) how to build the traversal lists without append.

A binary tree is either () or a three-element list (value left right). A value is a number or a single-character symbol. Example: t1 = (4 (2 (1 () ()) (3 () ())) (6 (5 () ()) (7 () ()))). Height of () is 0, height of a node is 1 + the max of its subtrees' heights. A leaf is a node whose two subtrees are both (). Left subtree is always visited before right.
S1.a (print-inorder tree) prints the inorder list on one line using display.
S1.b (print-all-traversals tree) prints three lines: inorder, preorder, postorder.
S1.c (print-height-and-leaves tree) prints one line: (height leaf-count).
Every function ends its output with a newline. Pass all state through arguments, prefer tail recursion where natural. The file has only definitions and no top-level calls.
Examples: t1 gives (1 2 3 4 5 6 7) / (4 2 1 3 6 5 7) / (1 3 2 5 7 6 4), and (3 4). t2 = (1 () (2 () (3 () ()))) gives (1 2 3) / (1 2 3) / (3 2 1), and (3 1). t3 = (a (b () ()) (c () ())) gives (b a c) / (a b c) / (b c a), and (2 2). The empty tree prints () for every traversal and (0 0).
```

```

Start the file with #lang racket/base and use accessors through cadr/caddr. Add the recursive-reading comment.
```
